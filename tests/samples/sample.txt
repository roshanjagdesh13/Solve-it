Question 5
----------
Explain the time complexity of the following algorithm and suggest an improvement:

  def find_duplicate(arr):
      for i in range(len(arr)):
          for j in range(i + 1, len(arr)):
              if arr[i] == arr[j]:
                  return arr[i]
      return None
